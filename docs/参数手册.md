# 装甲板自瞄模块参数手册

> [!info] 适用范围
> - 适用阶段：Phase 2（识别）/ Phase 3（追踪 + 角度）/ Phase 4（真相机）
> - 目标环境：Orin NX（`nvidia_nx`）独立工作空间 `/home/nvidia/vision_ws`
> - 当前阶段：**视频模拟调试中**，以下"测量值"全部用占位/参考值即可跑通；**真机部署才需实测**
> - 生成时间：2026-08-28

---

## 0. 参数总览

参数分三类，**处理方式完全不同**：

| 类别 | 性质 | 当前阶段怎么处理 |
|------|------|-----------------|
| **A. 需要测量的参数** | 物理量/几何量，须实测或标定 | 用参考/占位值，不真测 |
| **B. 可以调整的参数** | 算法/控制/匹配参数，靠调试确定 | 用经验初值，跑起来后按现象调 |
| **C. 固定依赖（无需调）** | ROS 话题名、TF 名称、包路径等 | 按约定固定 |

> [!note] 本文重点讲 A（测量）和 B（调整）。

---

## 一、A 类：需要测量的参数（真机部署时）

### A1. 相机内参（相机标定）

**所在文件**：`config/camera_info.yaml`

| 参数 | 含义 | 当前占位值 | 如何测量 |
|------|------|-----------|---------|
| fx | 焦距 x（像素单位 = 物理焦距 / 像元宽） | 近似值 | 棋盘格标定（见下） |
| fy | 焦距 y（像素单位） | 近似值 | 同上，同一组照片一起算 |
| cx | 主点 x（光轴在图像上的像素列） | 近似值 | 同上 |
| cy | 主点 y（光轴在图像上的像素行） | 近似值 | 同上 |
| k1, k2 | 径向畸变系数（桶形/枕形） | 0（视频阶段） | 标定输出 D 向量 |
| p1, p2 | 切向畸变系数（镜头与感光面不平行） | 0 | 同上 |
| k3 | 高阶径向畸变（大广角才有） | 0 | 同上（可选） |

**测法要点：**

- 标定板尽量占画面 **1/3 ~ 2/3**，角度覆盖 ±30°，距离覆盖实际交战范围
- 打印 A4 棋盘格标定板，固定相机，拍 **10~20 张**不同角度/距离照片
- 用 OpenCV `cv2.calibrateCamera()` 计算
- 结果**重投影误差 RMS < 0.5 像素**为合格

> [!warning] 何时必须
> Phase 4 接真实相机**前**必须标定，否则 PnP 解算的位置是错的。

### A2. 相机 ↔ 云台外参（TF：gimbal_link → camera_optical_frame）

**所在位置**：静态 TF 发布参数（launch_params.yaml 的 `odom2camera`，或 `static_transform_publisher`）

| 参数 | 含义 | 当前占位值 | 如何测量 |
|------|------|-----------|---------|
| x | 相机光心在云台旋转中心前方距离（米） | 0.10 | 尺量 / 手眼标定（见下） |
| y | 相机光心相对云台旋转中心左右偏移（米） | 0.00 | 尺量；安装居中一般 0 |
| z | 相机光心相对云台旋转中心的高度差（米） | 0.05 | 尺量 |
| roll | 相机绕前进轴相对云台的旋转（弧度） | 0.0 | 安装对齐，一般 0 |
| pitch | 相机相对云台的俯仰角（弧度） | 0.0 | 安装对齐一般 0；镜头有固定仰角则填实际值 |
| yaw | 相机相对云台的偏航角（弧度） | 0.0 | 安装对齐，一般 0 |

**测法要点（手眼标定 Hand-Eye Calibration）：**

- 云台上固定相机，前方放标定板，转动云台到**多个角度**各拍一帧
- 记录每个角度下云台的旋转量（编码器值）+ 相机标出标定板位姿
- 用 `cv2.calibrateHandEye()` 或 MATLAB / ROS `visp_hand2eye_calibration` 反解出相机相对云台的固定变换
- 精度高于尺量，**实车推荐用此法**

> [!warning] ⚠️ 注意
> `odom → gimbal_link` 这段**不是测量值**！真车上它是动态 TF，由 IMU / 云台编码器每个时刻实时发布。当前无电控，用静态固定姿态模拟。

### A3. 弹道物理参数（实车实测）

**所在文件**：`config/armor_solver_params.yaml`

| 参数 | 含义 | 当前参考值 | 如何测量 |
|------|------|-----------|---------|
| bullet_speed | 子弹初速（m/s） | 25 | 测速仪（如天幕测速）直接测；或高速录像测飞行时间反算，多颗取平均 |
| resistance | 空气阻力系数（速度衰减模型参数） | 0.092 | 试射统计：固定几个距离打靶，记录实际落点 vs 理论弹道，反推阻力系数，拟合最小误差 |
| side_angle | 侧向角度补偿（度，考虑自旋/空气动力侧偏） | 20 | 试射观察侧偏量反推（多数场景可先按厂商参数） |
| gravity | 重力加速度（m/s²） | 10（可用 9.8） | 按当地纬度/海拔取标准值，无需实测 |

**测法要点：**

- `bullet_speed` 最关键，直接决定弹道补偿曲线的**整体偏移**；建议用多个距离（3m / 5m / 8m）交叉验证
- `resistance` 影响**远距离（>6m）**弹道下坠修正，近距离影响小

> [!warning] 何时必须
> 实车打靶阶段（Phase 5 前后）。当前跑逻辑用参考值即可。

## 二、B 类：可以调整的参数（调试确定）

### B1. armor_solver —— 追踪与角度输出（Phase 3 主角）

**所在文件**：`config/armor_solver_params.yaml`

| 参数 | 含义 | 建议初值 | 怎么调（现象 → 动作） |
|------|------|---------|----------------------|
| sigma2_q_x（及 q_y/q_z/q_yaw 等） | EKF 过程噪声方差（目标运动的信任度） | 0.05 | 角度抖动/毛刺 → 调大；跟踪滞后、跟不上快速移动 → 调小 |
| r_x（及 r_y/r_z 等） | EKF 测量噪声方差（检测结果的信任度） | 4e-4 | 跟踪太飘、随检测抖动 → 调大；过度平滑、反应慢 → 调小 |
| tracker.max_match_distance | 新检测与既有轨迹的匹配距离阈值（米） | 0.5 | 多目标互相跳变/串线 → 调小；同一目标频繁丢失重匹配 → 调大 |
| lost_time_thres | 轨迹丢失判定时间（秒），超过则删轨迹 | 1.0 | 目标短暂遮挡即丢失 → 调大；想快速切换目标 → 调小 |
| max_tracking_v_yaw | 云台最大跟踪角速度（°/s），用于限制预测 | 60 | 预测角度超调/摆动 → 调小 |
| prediction_delay | 系统总延迟补偿（秒）：图像采集→处理→执行 | 0 | 实车时标定总延迟后填实际值（见下） |
| bullet_speed / gravity / resistance / side_angle | 弹道补偿用（同 A3） | 见 A3 | 见 A3 |
| window（开火窗口） | 允许开火的瞄准偏差窗口（与最小 1° 取大） | 按需求 | 误开火/要求高精度 → 调小；打不中/要求宽松 → 调大 |

**prediction_delay 的标定方法（Phase 5 实车）：**

- 测量链路总延迟：目标实际移动 → 相机成像 → 检测 → 追踪 → 输出角度的时间差
- 可对运动标定板录像，比较画面中板位置与解算角度的**相位差**估算
- 真车上通常结合电控回读实际云台角度来验证补偿效果

### B2. armor_detector —— 识别参数（Phase 2 已调）

**所在文件**：`config/armor_detector_params.yaml`

| 参数 | 含义 | 当前值 | 怎么调 |
|------|------|-------|--------|
| binary_thres | 二值化阈值（灯条亮度分界） | 90 | 漏检暗灯条 → 调小；反光/背景误当灯条 → 调大 |
| detect_color | 敌方颜色（0=红, 1=蓝） | 0 | 按实际敌方装甲板颜色切换 |
| use_pca | 是否用 PCA 角点矫正（提升小角度识别） | true | 角点定位不稳时关掉对比 |
| use_ba | 是否用 G2O BA 优化 3D 位姿 | true | 抖动明显且 BA 编译受限时设 false 对比 |
| classifier_threshold | 数字分类置信度阈值 | 0.7 | 误识别（背景当数字）→ 调高；漏识别 → 调低 |
| ignore_classes | 忽略的类别（不输出的标签） | ["negative"] | 需要过滤某类时加入 |
| max_detection_distance（若有） | 最大检测距离（米） | 按需 | 远处噪声多 → 调小 |

### B3. video_player —— 视频源参数（本机调试用）

**所在文件**：`config/video_player_params.yaml`

| 参数 | 含义 | 当前值 | 怎么调 |
|------|------|-------|--------|
| path | 视频文件路径 | input.avi | 换测试视频时改 |
| frame_rate | 发布帧率（Hz） | 30 | 模拟不同输入帧率（30/60/90）压测 |
| camera_info_url | 相机内参加载地址 | file:///home/nvidia/vision_ws/config/camera_info.yaml | **必须 file:/// 全路径**，否则内参 K 为空导致崩溃 |

### B4. 静态 TF 值（模拟云台位姿）

当前用 `static_transform_publisher` 发布，占位值：

| TF | 当前值 | 说明 |
|----|--------|------|
| odom → gimbal_link | 0 0 0 / 0 0 0 | 模拟云台固定（真机换成 IMU/编码器动态 TF） |
| gimbal_link → camera_optical_frame | 0.10 0 0.05 / 0 0 0 | 相机外参（真机见 A2，需测量） |

## 三、测量方法速查（汇总）

| 要测什么 | 方法 | 工具 | 精度 | 何时做 |
|---------|------|------|------|--------|
| 相机内参 K/D | 棋盘格标定 | OpenCV calibrateCamera / MATLAB | RMS < 0.5px | Phase 4 前 |
| 相机 ↔ 云台外参 | 手眼标定（首选）/ 尺量 | cv2.calibrateHandEye / visp | 毫米级 / 厘米级 | 真机装好后 |
| 弹速 bullet_speed | 测速仪 / 高速录像 | 测速仪、高速相机 | ±1% | 实车打靶 |
| 阻力 resistance | 多距离试射反推 | 靶纸、弹道拟合 | 经验级 | 实车打靶 |
| 系统延迟 prediction_delay | 相位差测量 | 录像 + 时间戳分析 | 毫秒级 | Phase 5 |

## 四、当前阶段一句话总结

> [!summary] 各阶段动作
> - **现在（视频模拟）**：A 类全部用占位/参考值（内参近似、外参 0.10/0/0.05、弹速 25/阻力 0.092），**不需要真测**
> - **Phase 3 开始前**：只需把 B 类参数确认好（用初值即可），即可跑通「追踪 + 角度输出」
> - **Phase 4**：标定相机内参（A1）
> - **真机 / Phase 5**：手眼标定外参（A2）+ 实测弹道（A3）+ 标定系统延迟
